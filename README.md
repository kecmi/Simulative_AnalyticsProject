# RFM-анализ клиентской базы аптечной сети

## Задача
Аптечная сеть хочет провести персонализированную SMS-рассылку перед 
спадом сезона, не тратя бюджет на клиентов с низкой ценностью.

## Подход
- Очистка данных: выделены только клиенты с дисконтной картой (11 из 12)
- RFM-метрики: Recency, Frequency, Monetary по каждому клиенту
- Пороги для сегментации: терцили (percentile_cont) для R и F
- Для Monetary — сравнение терцилей vs ABC-анализа (принцип Парето), 
  выбран ABC как более точно отражающий экономическую значимость клиента
- Визуализация распределений
